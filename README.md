# step-q.org

Static website for STEP-Q, a structured RFQ metadata layer for STEP-based manufacturing requests.

## Project structure

- `index.html` is the website entry point.
- `styles/` contains the section stylesheets.
- `sections/` contains reusable HTML fragments.
- `assets/` contains the website images and brand assets.
- `docs/integration/` contains integration notes.
- `docs/source/` preserves the original website package.
